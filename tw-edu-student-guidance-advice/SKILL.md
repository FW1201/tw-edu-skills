# 學生輔導建議

協助導師或任課教師把零散的觀察整理成可以行動的理解。輸出是教師專業判斷的輔助，不是診斷、不是輔導紀錄，也不取代輔導室的專業評估。

## 定位與邊界

- **做**：整理時間序、分出事實／教師詮釋／AI 推論、找模式與轉折點、保護與風險因子、至少兩個互斥的需求假設與查證方式、紅旗篩檢、現在／下週／下階段的行動、是否轉介。
- **不做**：心理或醫療診斷、特教鑑定、替學生或家長下結論、保存正式輔導紀錄。
- **與其他技能的分界**：
  - 整體理解一個學生 → 本技能。
  - 針對一個特定可觀察行為設計計畫 → `tw-edu-behavior-support`。
  - 已決定轉介或要開 IEP 會議 → `tw-edu-guidance-collaboration`。
  - 剛發生事件、需要判斷是否通報 → `tw-edu-incident-response`。

## 開始前

讀取 [共用工作方式](references/common/workflow.md)，檢查 `teacher-profile.md`。

**隱私守則**：學生只用代碼（學生A、S03 等）；不輸入姓名、學號、住址、家長職業或可辨識的家庭細節。若使用者提供了姓名，先請對方改成代碼再繼續，並提醒不要把對話內容上傳到未經學校同意的平台。

需要的輸入：
1. 學生概況：年段、背景脈絡（住校、轉學、社團等）、優勢、已知的支持服務。
2. 時間序事件：日期或週次、發生什麼、資訊來源。至少兩筆，越具體越好。
3. 教師個人看法：老師目前怎麼理解、擔心什麼。原文保留，不修飾。

事件不足兩筆或沒有時間資訊時，先給「接下來兩週要觀察什麼」的清單，不硬做分析。

## 思維路線

1. **三欄分開**：已知事實（可回查的紀錄與原話）／教師詮釋（老師的理解）／AI 推論（本技能的解釋，全部標為待驗證）。不把任何一欄寫成另一欄。
2. **依時間排序找模式**：同一類變化是否擴散到不同情境（課業、社團、人際、家庭）？哪個時點之前還穩定（轉折點）？
3. **保護因子與風險因子**：保護因子至少一項，例如一段穩定的關係、一個仍有興趣的活動、主動關心的家長。風險因子只寫觀察得到的，不從標籤推論。
4. **提出至少兩個互斥假設**：每個寫支持證據、不支持證據、怎麼查證。教師原本的看法要當成其中一個假設檢驗，不直接採信也不否定。
5. **紅旗篩檢**：自傷或自殺訊號、疑似受虐、疑似霸凌或性別事件、明顯失功能（長期缺席、無法進食或睡眠的描述）。觸發時：
   - 停止一般分析，先讀 [紅旗與通報分流](references/common/safety-red-flags.md)。
   - 「現在」欄必須有行動，轉介必須是「建議」。
6. **分層行動**：
   - 現在：教師能做的關心與安全安排（找安靜時間談話、不追問原因、表達會陪伴）。
   - 下週：與科任、宿舍、家長交換**必要**觀察。
   - 下階段：依觀察指標決定是否轉介。
   每項寫負責人與觀察指標。
7. **轉介判斷**：多個面向同時退縮、持續超過兩至三週、教師措施無效、或觸及專業範圍（情緒、創傷、家庭）時，建議轉介輔導室做介入性輔導評估。
8. **寫出限制**：資料來源偏誤、未取得學生本人說法、觀察期間短。

## 台灣情境要點

三級輔導分工、教師的角色與保密、與家長溝通的原則，見 [輔導情境要點](references/guidance-context.md)。

## 產出

依 [輸入規格](schemas/input.schema.json) 建立 JSON，[範例](examples/example.json) 只看結構。

```bash
python3 "$SKILL_DIR/scripts/generate_guidance_advice.py" --input "$TASK_DIR/input.json" --validate-only
python3 "$SKILL_DIR/scripts/generate_guidance_advice.py" --input "$TASK_DIR/input.json" --output "$TASK_DIR/guidance-advice.docx"
```

語意閘門會擋下：代碼像姓名、AI 推論或假設中出現診斷名稱、分析中出現標籤化用語、紅旗觸發卻沒有轉介或沒有「現在」的行動。互斥假設少於兩個時 schema 驗證失敗。

## 品質關卡

- 教師看法原文保留，並作為假設之一被檢驗。
- 每個 AI 推論都能指回至少一個事實。
- 建議的第一步是教師做得到、且不會傷害關係的行動。
- 不建議教師自行做專業評估、不建議對學生貼標籤或公開處理。
- 文件標示「非診斷」，正式紀錄依學校規定保存。

## 交接

- 決定轉介或需特教協作 → `tw-edu-guidance-collaboration`（帶時間序、教師已採措施、觀察指標）。
- 有特定行為需要計畫 → `tw-edu-behavior-support`（帶行為描述與情境）。
- 紅旗 → `tw-edu-incident-response`。
- 跟家長溝通 → `tw-edu-parent-communication`（只帶事實與合作請求，不帶 AI 推論）。
