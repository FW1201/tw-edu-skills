# 事件應變與通報分流

事件剛發生時，導師最需要的是「先做對的三件事」：確保安全、留下中性事實、判斷是否必須立刻交給學校程序。本技能先過紅旗閘門，再決定走一般衝突處理還是通報與交接。

## 定位與邊界

- **做**：中性事實紀錄、立即安全措施、紅旗篩檢、通報途徑與時限、導師不可獨自決定的事項清單、一般衝突的修復式對話、溝通範圍、後續追蹤。
- **不做**：判定是否構成霸凌或性別事件、調查取證、懲處決定、和解安排、法律意見。這些屬於學校依法設置的程序。
- **近似反例**：「學生上課一直離座」是行為支持（→ `tw-edu-behavior-support`）；「我想了解這個學生最近怎麼了」是個案分析（→ `tw-edu-student-guidance-advice`）。

## 開始前

讀取 [共用工作方式](references/common/workflow.md) 與 [紅旗與通報分流](references/common/safety-red-flags.md)。檢查 `teacher-profile.md` 的學段與學校窗口。

必要情境：何時知悉、從誰得知、目前是否還有人在危險中、學生代碼。**不需要等資訊齊全**：只要有紅旗訊號，就先輸出通報與交接清單，其餘標「待確認」。

## 思維路線

1. **安全第一**：現在是否有人受傷、仍在危險中、需要醫療或隔開？先列立即安全措施。
2. **記下知悉時間**：法定通報時限多自「知悉」起算，寫清楚教師何時、從誰得知。
3. **中性事實**：時間、地點、誰說了什麼（盡量原話）、看到什麼、資訊來源（目擊、陳述、轉述、紀錄）。不寫「霸凌」「故意」「說謊」這類判斷，也不寫標籤。
4. **紅旗閘門**（任一為是就走通報路線）：
   - 疑似霸凌：持續性的貶抑、排擠、欺負、攻擊，含網路。
   - 疑似校園性別事件：性騷擾、性侵害、性霸凌。
   - 兒少保護：疑似受虐、疏忽或其他傷害。
   - 自傷或傷人：言語、行為、計畫。
   - 校安事件：重大意外、暴力、藥物、失蹤。
   「疑似」就成立，不需要確定。
5. **紅旗成立 → 通報與交接路線**：
   - 列出通報途徑、對象、時限、依據，狀態先標「待通報」。
   - 列出導師**不可獨自決定**的事：不私下判定是否成立、不安排和解或對質、不自行訪談其他學生取證、不在群組說明、不承諾結果。
   - 修復式對話標為不適用；霸凌的「調和」須雙方同意並由學校依程序辦理。
   - 狀態只能是處理中、已通報待交接、已交接或待追蹤，不能是已結案。
6. **紅旗不成立 → 一般衝突處理**：評估是否適合修復式對話（雙方願意、權力不對等不明顯、無安全疑慮），寫出步驟：各自冷靜 → 說出發生的事與感受 → 影響 → 如何彌補 → 追蹤日期。
7. **溝通範圍**：對雙方家長、科任教師、班級分別說明到哪裡為止；不透露另一方學生資料。
8. **後續追蹤**：誰、做什麼、何時；一週內觀察雙方互動並記錄。

## 台灣情境要點

各類通報的時限、對象與程序細節見 [事件應變情境要點](references/incident-context.md)。重點：霸凌、性別事件、兒少保護、自殺行為的通報，法規多以「至遲 24 小時」為上限，且由學校權責人員向主管機關通報。

## 產出

依 [輸入規格](schemas/input.schema.json) 建立 JSON，[範例](examples/example.json) 只看結構。

```bash
python3 "$SKILL_DIR/scripts/generate_incident.py" --input "$TASK_DIR/input.json" --validate-only
python3 "$SKILL_DIR/scripts/generate_incident.py" --input "$TASK_DIR/input.json" --output "$TASK_DIR/incident-record.docx"
```

語意閘門會擋下：紅旗成立卻沒有通報項目、沒有列出不可獨自決定的事、狀態寫成已結案、或仍安排導師主導的修復式對話；事實欄出現標籤化用語也會被擋。

## 品質關卡

- 事實欄只有看到與聽到的內容，每筆有資訊來源。
- 紅旗欄五項都有明確的是或否。
- 紅旗成立時，第一個後續行動是交給學校權責人員，且有時間點。
- 溝通內容不洩漏另一方學生的資料。
- 生成紀錄不等於已通報，文件與回覆都要說明這一點。

## 交接

- 交給學務處或輔導室：帶事實紀錄、知悉時間、已採安全措施。
- 事件後的個別支持 → `tw-edu-student-guidance-advice` 或 `tw-edu-guidance-collaboration`。
- 給家長的說明 → `tw-edu-parent-communication`（敏感程度設為「正式程序」）。
- 班級整體氛圍修復 → `tw-edu-classroom-culture`。
