# 評量法規要點

查核日期：2026-10-09。條文以轉述呈現，使用前回查全國法規資料庫。

## 國民小學及國民中學學生學習評量辦法（113.04.24 修正，113.08.01 施行）

舊名為「國民小學及國民中學學生成績評量準則」，引用時用現行名稱。

- 第3條：日常生活表現評量的範圍包括出缺席情形、獎懲紀錄、團體活動表現、品德言行表現、公共服務及校內外特殊表現等。
- 第8條：日常生活表現由導師評量，並參據學校各項紀錄、授課教師、學生同儕及法定代理人的意見。
- 第10條第4項：日常生活表現依行為事實記錄，可酌予提供具體建議；不作綜合評價，也不轉換為等第。
- 第11條：評量紀錄與具體建議每學期至少以書面通知學生及法定代理人一次；學校可公告分數分布，但不得公開個別學生的班級或學校排名。

## 高級中等學校

依「高級中等學校學生學習評量辦法」及學校規定；日常生活表現的記錄方式與項目使用前回查。

## 寫作提醒

| 避免 | 改寫方向 |
|---|---|
| 乖巧懂事 | 具體寫出做了什麼，例如主動協助同學整理座位 |
| 上課不專心 | 寫行為事實與建議，例如作業繳交 8/12 次，可試著用聯絡簿記錄作業 |
| 表現優良、甲等 | 不寫等第或綜合評價，寫具體表現 |
| 是班上最好的 | 不與其他學生比較 |
| 問題學生、屢勸不聽 | 不寫標籤，只寫事實與成長方向 |
