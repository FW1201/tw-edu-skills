# 學生行為支持

針對一個**可觀察的特定行為**，從「為什麼會發生」出發設計支持，而不是從「怎麼處罰」出發。所有功能判斷都是待驗證的假設，不是診斷。

## 定位與邊界

- **做**：行為定義、基線、ABC 紀錄、功能假設、支持層級判斷、前事調整、替代行為教學、回應方式、資料蒐集與再檢核、停止與轉介條件。
- **不做**：醫療或心理診斷、特教鑑定、懲處決定、全面性個案分析（→ `tw-edu-student-guidance-advice`）、事件通報（→ `tw-edu-incident-response`）。
- **近似反例**：「這個學生最近怪怪的，不知道怎麼了」沒有特定行為，先用 student-guidance-advice；「學生打人了」先走事件應變與紅旗篩檢。

## 開始前

讀取 [共用工作方式](references/common/workflow.md)，檢查工作區 `teacher-profile.md`。學生一律用代碼（如 學生A、S03），schema 會拒絕看起來像姓名的代碼。

必要情境：學段、行為發生的科目或時段、觀察期間與次數、已試過的做法。缺少基線資料時，先產出「兩週觀察紀錄表」的建議，不直接寫計畫。

出現自傷、傷人、疑似受虐或其他紅旗時，先讀 [紅旗與通報分流](references/common/safety-red-flags.md)，`safety_check.red_flags_present` 設為 true，支持層級只能是專業轉介或行政協助。

## 思維路線

1. **把行為寫成看得到的動作**：誰在什麼情境做了什麼、持續多久。「不專心」「態度差」要改寫成「獨立練習時離座 2–5 分鐘」。
2. **先看基線**：頻率、強度、發生情境、不發生的情境。沒有不發生的情境作對照，功能假設就很難檢驗。
3. **ABC 紀錄**：每筆分前事（A）、行為（B）、後果（C）。注意後果是否意外增強了行為（例如同學笑、任務被取消）。
4. **功能假設至少一個、最好兩個**：取得注意、取得物品或活動、逃避任務、逃避人際或感官刺激、感官調節、尚不確定。每個假設都列支持證據與反向證據，狀態只能是「假設／初步支持／不支持」。
5. **判斷支持層級**：班級層級（全班調整就能改善）→ 個別層級 → 家庭協作 → 專業轉介（輔導室、特教）→ 行政協助（安全、人力）。依需求決定，不依標籤決定。
6. **先調前事**：任務長度與難度、等待時間、選擇權、視覺提示、座位與動線、轉換預告。讓行為「不需要發生」，而不是永久降低期待。
7. **教替代行為**：選一個學生現在就做得到、且能達成同樣功能的行為（例如用求助卡代替離座）。寫出教學步驟與增強方式，增強要逐步撤除。
8. **設計回應**：行為發生時教師怎麼做，原則是平靜、私下、短句、回到任務。不得體罰、羞辱、連坐或侵害財產；處罰前視情況給學生陳述意見的機會。
9. **再檢核與停止條件**：誰、用什麼方式蒐集資料、哪一天檢視；什麼情況要調整假設、停止計畫或轉介。

## 台灣情境要點

- 正向管教、違法處罰的範圍與一般管教措施的限制，以及教師與輔導室的分工，見 [行為支持情境要點](references/behavior-context.md)。
- 中央的「教師輔導與管教學生辦法」已廢止，現行依各校經校務會議通過的辦法與教育部注意事項。

## 產出

依 [輸入規格](schemas/input.schema.json) 建立 JSON，[範例](examples/example.json) 只看結構。

```bash
python3 "$SKILL_DIR/scripts/generate_behavior_support.py" --input "$TASK_DIR/input.json" --validate-only
python3 "$SKILL_DIR/scripts/generate_behavior_support.py" --input "$TASK_DIR/input.json" --output "$TASK_DIR/behavior-plan.docx"
```

語意閘門會擋下：學生代碼像姓名、回應或預防中含體罰／羞辱／連坐等措施、行為定義或假設中寫入診斷名稱、紅旗成立卻只用班級或個別層級、替代行為與目標行為相同。

## 品質關卡

- 行為定義能讓另一位老師照著觀察並得到相近次數。
- 每個功能假設都有反向證據欄位（可以是空的，但要想過）。
- 前事調整至少一項，且不是單純降低學習目標。
- 回應方式可在全班面前私下執行，不公開點名羞辱。
- 有明確的再檢核日期與停止、轉介條件。
- 與家長溝通的內容另由 parent-communication 產生，不直接把本計畫給家長。

## 交接

- 需要輔導室評估或 IEP 調整 → `tw-edu-guidance-collaboration`（帶基線、ABC 紀錄、已採措施與結果）。
- 需要跟家長合作 → `tw-edu-parent-communication`（只帶行為事實與合作請求）。
- 全班性的程序問題 → `tw-edu-classroom-culture` 或 `tw-edu-homeroom-operations`。
