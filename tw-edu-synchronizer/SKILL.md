# 教師偏好設定

把老師不想每次重複說的資訊存成一份工作區設定檔。其他技能每次啟動都會讀它，但本次對話的明確要求永遠優先。

## 定位與邊界

- **做**：建立、更新、回讀 `teacher-profile.md`。
- **不做**：保存學生名單、學生診斷、輔導或特教資料、家長聯絡方式、健康資訊、帳號密碼；同步 GitHub 或安裝其他技能。

## 開始前

讀取 [共用工作方式](references/common/workflow.md)。先讀工作區已有的 `teacher-profile.md`；已有的欄位不要重問，只問缺少且會影響輸出的欄位。

## 思維路線

1. **讀現況**：有檔案就讀；沒有就建立。
2. **只問必要的**：一次最多問三題，提供選項。
3. **欄位**：
   - 稱呼
   - 任教科目、學段與年級
   - 教材版本
   - 職務：導師、科任、兼組長或主任（處室）
   - 學校規模（班級數區間）與縣市：影響班級經營與行政技能的建議（例如小校一人多職、縣市公文與課程計畫格式）
   - 一般學習需求：例如班上常見的學習差異類型，不寫個別學生
   - 輸出偏好：格式、語氣、字數、是否要附教師講稿
4. **更新**：只改指定欄位，其餘保留；未知欄位留空，不補造。
5. **回讀確認**：存檔後讀回，摘要實際更新了哪些欄位。
6. **提醒界線**：如果使用者想存學生或家長資料，說明不適合放在設定檔，並建議改用學校系統。

## 台灣情境要點

- 縣市會影響：公文稱謂（教育局或教育處）、課程計畫備查格式、部分行政流程。
- 學校規模會影響：一人多職時的權責分工建議。

## 產出

Markdown 檔 `teacher-profile.md`，放在目前工作區。範本：

```markdown
# 教師偏好設定
- 稱呼：
- 任教科目：
- 學段與年級：
- 教材版本：
- 職務：
- 學校規模與縣市：
- 一般學習需求：
- 輸出偏好：
```

本技能不使用生成腳本。

## 品質關卡

- 沒有學生、家長的個資或任何敏感資料。
- 未更新的欄位保持原樣。
- 存檔後已回讀確認。
- 沒有宣稱設定已同步到 GitHub 或其他裝置。

## 交接

設定完成後，可直接使用任何 tw-edu 技能，例如 `tw-edu-lesson-plan-108` 或 `tw-edu-homeroom-operations`。
