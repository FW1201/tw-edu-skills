# 品質關卡與候選驗證案例

查核日期：2026-11-22。本文件是下一階段需求，尚未建立或執行生成器測試。

## 輸入、來源與輸出

最低候選輸入：任務用途、學段及課程別、題幹／資料、數學物件與約束、輸出格式、尺寸、黑白／彩色、是否顯示解答。選填：字型、精度、是否比例精確、來源、單位、可編輯要求、替代文字。資訊不足時詢問或標示假設，不得憑空補成正式數據。

候選交付：可追溯的參數／資料、視需要的向量圖與點陣預覽、目標文件、替代文字、校驗記錄。區分「可重新生成」、「可編輯圖形物件」、「可編輯公式」和「可編輯純文字」；不同格式的支援不可預先保證。

## 數學品質

1. 以原始參數或符號／數值計算檢查，不以圖像看起來正確代替驗算。圖示非按比例時明示；已知與待求、近似與精確需區分。
2. 角度方向與角弧、幾何點的位置與關係、數線等距、端點、函數定義域、圖表資料守恆、表格合計、LaTeX 結構和題解一致。
3. 保留精確值供計算，顯示時才依指定方式取近似；驗收容差依題目與輸出用途訂定。
4. 圖表標題、來源、日期、單位、分母、座標與比例不應誤導。圖例不可只靠顏色；保護學生個資。
5. 考卷不得把答案、作圖輔助線或隱藏圖層洩漏至學生版；教師版有答案與檢核依據。

## 輸出與可及性

- 檢查縮放與列印後線寬、最小字級、中文缺字、黑白區辨、元素遮擋、裁切、分頁及表格斷行；在實際目標軟體中開啟。
- 圖像提供簡短 alt 及必要時長描述；有互動的物件應考慮鍵盤操作與螢幕閱讀器。數學語音在目標瀏覽器及繁中語系實測；參考 [S08](sources.md)。
- 數據與程式可重現：記錄輸入、版本、隨機種子、所用字型及依賴；輸出檔案與原始資料數值交叉核對。
- 以學生實際閱讀與教師審題為最後關卡；自動檢查通過不等於教學或正式命題審定。

| ID | 輸入／任務 | 必要預期 | 反例或失敗條件 |
|---|---|---|---|
| T01 | 以正 x 軸逆時針畫 35° 與 115° | 射線角度與標示相符；弧線指向指定角 | 銳角錯成 145° 或弧線落在另一側 |
| T02 | 畫順時針旋轉 270° | 弧線顯示完整旋轉方向與大小 | 用 90° 的短弧代替 |
| T03 | △ABC 的高落在 BC 延長線 | 垂足在線延長處、直角標記正確 | 垂足被強制放在線段 BC 上 |
| T04 | 區間 x > −2 | −2 為空心點、向右射線 | 實心點或朝左 |
| T05 | 0 到 1 的 3/4 位置 | 四等分、點落在第三刻度 | 3/4 點距離 0 為 2/3 單位 |
| T06 | 分類 A=2、B=3、C=5 | 表格總數 10；圓形圖 20%、30%、50% | 總數、百分比、扇形角不一致 |
| T07 | 不等組距頻率直方圖 | 註明縱軸意義；若面積代表次數則高度按頻率密度 | 高度直接當頻數導致面積誤導 |
| T08 | f(x)=1/x | x=0 處不連線；畫出相應漸近行為 | 曲線穿越或連接漸近線 |
| T09 | 聯立方程與推導 | 等號對齊，符號及教師答案可重算 | 括號遺失、上標範圍錯誤 |

| T11 | 繁中圖表輸出為目標 PDF／DOCX | 軸文字可讀、中文不缺字，頁面無裁切 | 系統替代字或中文字變方塊 |

## 後續人工驗收

邀請不同學段數學教師審閱真實教材情境；確認課綱及出版社記號慣例、檢查紙本和數位版、無障礙體驗；紀錄被測版本與未涵蓋案例。題目或資料涉及學生時先去識別化。
