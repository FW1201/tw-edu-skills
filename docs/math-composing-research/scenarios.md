# 數學視覺與排版情境目錄

研究清單 v0.1｜2026-11-22。以下學段是**可能使用的情境**，不是該學段課綱承諾。幼兒園圖像需求待查教保大綱；高中不同類型與選修須另查。S01–S10 見 [來源](sources.md)。每項均可用於教師講解、學習單、試卷或互動探索，並依任務決定要顯示或隱藏答案。

## 角度與平面幾何

| ID | 學段候選 | 情境與具體圖像 | 驗收重點 |
|---|---|---|---|
| G01 | 小中高年級 | 指針、門扇或路口的旋轉角與方向 | 頂點、起始邊、箭頭、順逆方向及角弧一致；不把旋轉角誤當短夾角 |
| G02 | 小中高年級 | 量角器讀數、畫 35°、115°、反身角 | 角弧、刻度起點與左右方向一致；角度實際數值正確；S03 |
| G03 | 小中高年級 | 銳角、直角、鈍角、平角、周角辨識 | 直角標記、角弧範圍、非等比例提示準確 |
| G04 | 小中高年級 | 三角形依邊與角分類、畫高 | 垂足、延長線、內外高、等邊刻痕可辨 |
| G05 | 小中高年級 | 四邊形、多邊形與對角線 | 頂點順序不交叉；平行、等長標記符合條件 |
| G06 | 小中高年級 | 圓心、半徑、直徑、弦、扇形 | 端點真在圓周；半徑相等、弧線與扇形範圍一致 |
| G07 | 小中高年級 | 周長、方格面積、分割重組、複合圖形 | 邊長、單位與面積守恆；避免用外觀代替題設 |
| G08 | 小中高年級 | 線對稱、平移、旋轉、放大縮小 | 對應點清楚；對稱軸、轉動中心、比例符合變換 |
| G09 | 國中 | 相交線、平行線截角及三角形角度推理 | 平行和角記號分清已知與待求；未知量不洩題 |
| G10 | 國中 | 全等、相似、畢氏定理與三角比 | 對應順序與比例正確；S-8-4 見 S02 |
| G11 | 國中／高中 | 尺規作圖、垂直平分線、角平分線 | 保留必要作圖弧與作圖順序；不可把示意圖當可作圖證明 |
| G12 | 國中／高中 | 圓周角、切線、弦與交點 | 相切條件、角弧、內外點關係以幾何計算核對 |
| G13 | 高中 | 向量、內積及投影 | 向量箭頭方向、長度、夾角和投影位置正確 |
| G14 | 高中 | 坐標幾何：直線、圓、圓錐曲線 | 軸刻度、交點、切線、定義域與圖像一致；課程類別待核 |

## 交叉需求

題目／講義／教師答案版本分離；能標未知數而不洩漏答案；黑白列印、投影、縮放、色盲辨識；繁中標籤、替代文字與圖形長描述；依年齡調整視覺複雜度。演算法圖形須同時保留參數與來源；不使用生成圖像承諾精確角度、比例或文字正確性。
