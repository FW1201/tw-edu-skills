# v3 → v4 遷移

重新啟用 FW1201/tw-edu-skills，維持現有 21 個獨立技能。保留 v3.1-final tag，舊安裝不會自動更換。

1. 備份個人自訂技能，檢視新版原始碼與 manifest。
2. 執行 bash install.sh --agent codex --dry-run（或 claude-code）。若發現自訂內容，先比較，明確選擇 --force 才更新；安裝器保留備份。
3. 在工作區建立 teacher-profile.md，寫入一般偏好；本次指令優先於設定。
4. 舊生成器只傳主題／科目的方式，改成根據各技能 schemas 與 examples 提供 --input JSON。示範請明確使用 --example。
5. 簡報預設可編輯；整頁圖片須選 image。試卷學生版與答案版分開交付。

單一 Skill 不依賴上層共用文件或其他技能。安裝器不安裝全域 Python 套件。

## 回復

安裝器會先暫存並驗證本次選取的所有技能，再開始替換。全套更新若任一項替換失敗，已替換項目會依反向順序回復，未替換項目保持原狀；若回復本身失敗，安裝器會明確報告未完整回復的路徑，供人工處理。成功更新的舊版則保留於安裝根目錄下 `.tw-edu-<name>.backup-<id>`。手動回復前先停止使用該技能、保存新版修改，再將已確認的備份恢復為原技能名稱。
