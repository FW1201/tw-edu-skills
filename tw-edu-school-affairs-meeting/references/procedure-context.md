# 校事會議程序要點

依據：高級中等以下學校教師解聘不續聘停聘或資遣辦法（115.01.12 修正）。查核日期：2026-10-09。條文以轉述呈現，正式引用請回到全國法規資料庫（pcode H0060087）。本頁不是法律意見。

## 階段與條次

| 階段 | 要點 | 條次 |
|---|---|---|
| 日常瞭解 | 學校得以巡堂、觀課、溝通、行政晤談等方式瞭解教學與互動，必要時作成紀錄 | 第1條之1 |
| 受理審查 | 校長邀集調查專業人才庫人員 1 人及教師、家長代表各 1 人開會，校長無表決權；無記名投票過半數得不予受理；檢舉人未具真實姓名等情形得不受理；20 日內書面通知是否受理 | 第9條 |
| 案件分流 | 涉成績考核辦法懲處者適用考核辦法；涉解聘、不續聘、停聘等情形由校事會議組調查小組 | 第9-1條、第13條 |
| 校事會議 | 受理後 7 個工作日內召開；委員 5 人，含校長、家長、行政、教師會代表及學者專家或社會人士；任一性別不少於三分之一 | 第12條 |
| 調查小組 | 3 或 5 人，全數外聘，自調查專業人才庫遴選，至少 1 名法律專家（偏遠地區例外）；校事會議委員不得同時擔任調查小組委員 | 第14條、第16條、第18條 |
| 訪談 | 全程錄音錄影，受訪者不得自行錄音錄影；受訪者得偕同輔佐人，不超過 2 人，陳述不當者得禁止 | 第19條、第22條 |
| 調查期限 | 自首次會議起 2 個月內完成報告，得延長 2 次，每次不超過 1 個月並通知當事人；無正當理由拒不配合者得不待陳述逕行作成報告 | 第21條 |
| 審議決議 | 移送教評會、移送考核會、自行輔導或申請輔導、結案 | 第25條 |
| 輔導改善 | 輔導小組 3 或 5 人，含輔導人才庫輔導員至少 1 人；輔導期以 2 個月為原則，得延長 1 個月；拒絕輔導或出席未達三分之二視為改善無成效 | 第27–29條 |
| 教評會 | 移送前，學校至遲 7 日前提供調查報告及輔導報告 | 第43條 |
| 終局通知 | 終局處理後 10 日內書面載明事實、理由及救濟方法、期間、受理機關 | 第47條、第48條 |
| 保密 | 參與人員對檢舉人、行為人、被害人身分負保密義務；對外報告以代號取代姓名 | 第5條、第7條、第48條 |
| 迴避 | 依行政程序法第32、33條 | 第59條 |
| 救濟 | 行為人得就終局實體處理依法提起行政爭訟 | 第49條 |

## 教師可以先確認的問題（向學校人事或教師會）

- 本案目前在哪個階段？是否已受理？
- 調查小組首次會議日期？期限何時屆滿？
- 訪談時間、地點、輔佐人的資格與登記方式？
- 可否申請閱覽或提供相關資料？方式為何？
- 本案屬校事會議程序還是考核辦法程序？

## 可以尋求的支持

- 學校教師會或縣市教師會、教師職業工會的法律諮詢與陪同（各會服務內容不同，先洽詢）。
- 律師（自費或依所屬團體方案）。
- 教育部教師諮商輔導支持中心（心理支持，見 teacher-wellbeing）。
