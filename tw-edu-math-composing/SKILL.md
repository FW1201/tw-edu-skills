# 臺灣數學教材設計與排版

## 定位與邊界

單元可從教材設計、數學圖文或排版開始。教案、學習單、簡報使用現有 tw-edu-lesson-plan-108、tw-edu-worksheet-creator、tw-edu-slides-creator 的架構與輸出；本技能提供數學圖文、驗算及專用考卷排版。整份段考涉及雙向細目表、配分與正式命題時，由試卷工作流程主責，本技能提供數學素材與排版。涉及數學模型、數值運算或統計圖表的程式與視覺化，由本技能提供數學設計和校驗，依任務交付程式或資料圖。一般介面、登入和營運儀表板依其主要工作流程處理。

## 開始前

讀取[共用工作方式](references/common/workflow.md)、現有題目、教師指定範圍、目標格式及工作區已有的 `teacher-profile.md`。若既有套組提供共用 workflow，依照該工作方式交接。以本次明示要求為準。若老師指定校版字型，記入輸出規格。考卷依題長和作答空間選單欄、雙欄或按題組混排。若教師指定左右欄題區，在右欄首題設定換欄。只在年級、先備或題目條件會改變成果且無法推知時詢問。既有教材的修訂先分清楚補圖、排版與內容改寫。

## 思維路線

1. 從單元與目標開始 → 讀 [教材設計](references/design.md)，再由既有教案與教材技能主責設計、排版。數學圖、公式及程式由本技能提供或校驗。
2. 製作或驗證圖表、公式、數學程式 → 讀 [數學圖文](references/math.md)，先決定座標、單位、模型或統計量，再依指定環境輸出圖形、公式、資料或程式。
3. 已有題目要排版，或內容準備完畢 → 讀 [排版輸出](references/output.md)，以同一來源產生學生版與所需教師版。
4. 發現題意歧義、圖文矛盾或欠缺數據 → 就地標記並列出待確認項；其餘可驗證內容先完成。

## 台灣情境要點

使用繁體中文與教師指定記法。課綱對照依實際學段及高中課程類別回查。入口、轉化案例和證據界線見 [教材設計](references/design.md)。

## 產出

依 [套件整合流程](references/suite.md) 交接，並依 [教材資料格式](references/output.md) 交付可重製的資料、數學來源與所需文件。內附 Python 產生器以結構化公式輸出 Word 原生 OMML。紙本題號採「一、／1、／（1）」三層，作答區保留純空白。原創學習單與考卷案例可用於重跑。可只交付圖形與來源，或輸出完整 A4 文件。

## 品質關卡

驗算參數、數據與解答。核對根號橫線涵蓋的被開方數，以及題幹、解析與圖中標籤的上下堆疊分數。檢查角弧、刻度、軸單位、數學符號、圖題配對與作答空間。開啟實際 DOCX 和 PDF，核對指定與實際使用的字型、內嵌狀態、換行、黑白可辨與公式編輯。獨立算式若要求算出結果，確認已有等號及純空白填答空位。題內行距、題間距與手寫留白分別檢查。雙欄檢查題序、欄寬、題圖及作答線，長題或寬表格優先安排全寬。掃描學生版正文、替代文字及隨附檔案，確保答案留在教師版。將未能驗證的格式或內容列進交付說明。

## 交接

以題目 ID 對應學生題幹、圖文來源和教師答案。交給學習單、試卷、簡報或教材審查流程時，一併提供來源、可編輯範圍及待確認事項。現有通用文件技能依各自 schema 使用。考卷先驗證題型、題數、配分與答案，再用本技能版型產生學生卷及教師卷。
